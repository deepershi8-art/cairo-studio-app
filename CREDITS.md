# Audio credits

All sounds in the Suite demonstrations are real recordings or measured acoustic responses, trimmed, normalised and re-encoded (MP3 96 kbps mono; impulse responses as 16-bit WAV). Processing in the app (panning, EQ, room modes, comb filtering, wall loss, convolution) is done live with the Web Audio API.
